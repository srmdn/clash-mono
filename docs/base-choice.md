# Base Choice

Primary reference:
- `Iosevka`

Why:
- coding-first
- highly legible at small size
- good metrics reference for monospace work
- open-source and widely used in editor fonts

Secondary reference:
- `Source Code Pro`

Why:
- neutral skeleton
- easy to compare against for spacing and proportion

Rule:
- use as metrics/style reference only
- do not copy outlines
- final geometry stays original
