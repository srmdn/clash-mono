# Reference Policy

Allowed:
- screenshots of public UI
- original notes and sketches
- open-source font metrics and build docs

Not allowed:
- importing proprietary font files as source
- tracing outlines from Supercell font files
- copying contours, points, or components from proprietary assets

Usage rule:
- references inform proportion, weight, terminals, and spacing
- references do not become geometry

If in doubt:
- redraw from scratch
- document the decision
