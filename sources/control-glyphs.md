# Control Glyphs

Core control set for first draw pass:

- `I`: straight stem, clean top and bottom, no confusion with `l`
- `l`: similar stem, but with distinct terminal or hook
- `1`: stem with foot or notch, not a bare line
- `O`: round, even, optically balanced
- `0`: same skeleton as `O`, but with inner cut or angled stress
- `{}`: brace forms with visible waist and sturdy shoulders
- `[]`: square, stable, compact
- `()`: open, friendly, consistent curve tension
- `< >`: sharp enough to read in code, not pointy to the point of noise
- `=`, `-`, `+`, `*`, `/`, `\`, `|`: simple, high contrast, no decoration

Testing order:
1. set these glyphs first
2. preview in editor at small size
3. compare `I/l/1` and `O/0`
4. adjust spacing before styling
